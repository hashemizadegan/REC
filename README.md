# REC Platform (Russia-Eurasia Commerce)

**REC** is a specialized B2B trade execution and cross-border settlement platform connecting Iranian producers/exporters with Russian buyers and distributors.

## 🎯 Target Pilot Scope (8-Week Phase)
- **Primary Commodities:** 
  - Dates (HS Code: `0804.10` - Mazafati, Piarom, Zahedi)
  - Pistachios (HS Code: `0802.51`, `0802.52` - Fandoghi, Ahmad Aghaei, Akbari)
- **Target Route:** Iran (Anzali / Bandar Abbas / Astara) ↔ Russia (Astrakhan / Moscow)
- **Settlement Architecture:** Dual-currency Ruble/Rial clearing & BRICS Pay protocols.
